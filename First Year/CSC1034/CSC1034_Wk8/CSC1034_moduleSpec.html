Course Contents

This module introduces essential concepts and skills for developing data-driven web applications, covering relational and NoSQL databases, and client-side technologies such as HTML, CSS and JavaScript.

Emphasising best practice software design principles, development activities are underpinned by industry standard approaches to software modelling, design methodologies, software testing principles and key security considerations.

Additionally, this module fosters transversal skills including communication, teamwork, problem-solving and agility in a team environment.

Aimed at providing a strong technical and theoretical foundation, this module equips students for the dynamic field of web development and software design, blending technical competencies with essential soft skills for the software industry.

Learing Outcomes

Upon succesful completion of this module, students will be able to:

  1. Design and implement relational and NoSQL databases, understanding their respective use-cases and benefits.
  2. Develop interactive web pages adhering to modern web standards using HTML, CSS and JavaScript.
  3. Employ fundamental software design and testing principles in the development process, integrating modelling techniques and ensuring code reliability.
  4. Understand and apply fundamental principles of security in web development and database management, recognising common vulnerabilities.
  5. Apply and evaluate transversal skills associated with software development including effective communication, teamwork, problem-solving and adaptability.

Glossary

HTML
HyperText Markup Language used to structure content on web pages.
CSS
Cascading Style Sheets used to control the presentation and appearance of HTML content.
JavaScript
A programming language used to create interactive behaviour in web applications.
Relational Database
A structured data storage system that organises data into tables with relationships between them.
NoSQL Database
A flexible, non-relational data storage system often used for large-scale or unstructured data.
Transversal Skills
Skills such as communication, teamwork and problem-solving that apply across disciplines.
